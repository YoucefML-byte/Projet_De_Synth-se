# Projet de synthèse – Avis de joueurs Steam

Outil de suivi de la réception des jeux vidéo à partir des avis Steam (M2 SID, Université de Lorraine).

L'outil collecte régulièrement les avis d'un panel de jeux, les historise dans un entrepôt de données et les analyse pour :

- expliquer le score d'un jeu (thèmes de satisfaction et de plainte) ;
- mesurer l'impact des mises à jour ;
- détecter les anomalies (pics d'avis négatifs, review bombing) ;
- présenter les résultats dans un tableau de bord.

## Organisation

Le projet est mené en méthode agile, avec des sprints de 3 semaines.

- `main` : version stable du projet
- `Sprint0` : travaux du sprint 0 (vision du produit, backlog initial, architecture…)
